Validates message ranges and generates intelligent summaries for compaction. For each range, an LLM call generates a concise summary (1-3 sentences) and 3-7 semantic index terms for future retrieval.

Usage: call with `ranges: [{ startMessageId: "msg_abc", endMessageId?: "msg_xyz" }]`; ranges are inclusive and may be a single message when `endMessageId` is omitted.

Validation rules:
- All message IDs must exist in the session
- startMessageId must come before endMessageId chronologically (message IDs are lexicographically sortable)
- Start and end messages must not be already archived (have `archive` or `archivedBy` fields)
- Multiple ranges must not overlap with each other
- Archived messages in the middle of a range are allowed

Output includes:
- Range details with message counts and token estimates
- Generated summary capturing essence of content
- Index terms for semantic retrieval
- Total messages and tokens ready for archival

Note: This tool generates summaries but does not yet update message metadata with archive fields (Story 2.3).
